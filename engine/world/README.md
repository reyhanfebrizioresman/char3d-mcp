# Mode bebas / world recipes

A world is data, validated by the **same** closed JSON Schema in the provider,
MCP and Blender processes. `world_schema()` publishes the entire schema plus
all 38 generators, parameter defaults/ranges, descriptions and budgets.
`compose_world(recipe, build=False)` runs pure preflight: it imports no `bpy`,
reads no files, never starts Blender, and returns a normalized recipe, warnings
and cost. There is no Python/code field, expression language, module selector,
asset URL or file path. Unknown keys fail with a JSON path. No `eval` or `exec`
is involved in generation or composition.

```json
{
  "version": 1,
  "name": "The jade guardian",
  "seed": 17,
  "duration_s": 4,
  "elements": [
    {"id": "gateway", "generator": "arch_gate",
     "params": {"width": 6, "height": 7, "style": "beam"},
     "transform": {"location": [0, 12, 0]}},
    {"id": "guardian", "generator": "serpent",
     "params": {"length": 65, "radius": 1.15, "segments": 144, "coil": 1},
     "transform": {"location": [0, 15, 9], "rotation_deg": [0, 0, -18]},
     "animation": [{"kind": "bob", "amplitude": 0.35, "speed": 0.5}]}
  ],
  "stage": {"area": [7, 6], "standing": [[-0.85, 0, 0], [0.85, 0, 0]]},
  "look": {"preset": "misty_morning", "haze": 0.006},
  "camera_hints": {"hero": {"location": [26, -39, 17], "target": [0, 12, 7], "lens": 43}}
}
```

Units are meters; Z is up, characters face -Y. `transform` has local XYZ
`location`, XYZ Euler `rotation_deg`, XYZ positive `scale`. Element transforms
contain instance transforms. Either `instances: [transform, ...]` or
`scatter: {area: [width,length], count, seed?, min_distance?, avoid?}` can place
an element; `avoid` is local XY circles `[x,y,radius]`. Bounded rejection sampling
fails clearly if the count cannot fit. The same seed/recipe produces the same
geometry and motion, with no camera-dependent thinning or global RNG changes.

`palette` maps color names to linear RGB. `materials` maps names to `{color,
roughness, metallic, emission, transparency}`; color is RGB or a palette name.
Transparency presets are `opaque`, `glass` (alpha .55), `mist` (alpha .25),
using dithered surface rendering, not fluid or volume simulation.
An element's `material` applies one material recipe to every part;
`material_overrides` maps original generator material names to material recipes
for selective recoloring. Keep creature eyes and belly contrast readable.
`lights` allows bounded point/spot/area practicals. Lantern swarms use emissive
paper with no light per lantern. `sky` delegates the established outdoor sky
preset/strength/rotation; `look` and `weather` delegate cinematic/weather tools.

`camera_hints.hero` is an explicit location/target/lens. Optional `medium` and
`close` hints create owned portrait cameras, returned as `portrait_cameras`.
Each accepts `f_stop` (1.2–32) for saved DOF, focused on its target. Portrait
coordinates are absolute; choose eye/chest height for the actual cast and put
foliage, cloud banks or practicals 3–8m behind the stage for depth. An optional
`establishing_path` animates that camera through XYZ points. `stage` contains
world `location`, floor `area`, local `standing` positions, floor flag,
`surface` and color, plus `seats` referencing chair/bench/sofa/stool elements.
An owned walkable floor is generated by default. Use the returned `hero_camera`
with `render_preview(camera=hero_camera, engine_name="eevee")` for its composition;
named camera previews bypass existing script shot markers. Walking directions still use
absolute world XY coordinates. Static obstacle and foot-lock rules still apply.

## Catalog

All 26 nature generators are available: `tree`, `bush`, `hedge`,
`grass_field`, `flowers`, `reeds`, `rice_paddies`, `hills`, `mountains_backdrop`,
`rocks`, `cliff`, `path`, `lake`, `river`, `sea`, `waterfall`, `clouds`,
`falling_petals`, `birds_flock`, `butterflies`, `fireflies`, `fence`, `lantern`,
`wooden_bridge`, `gazebo`, `village_house`.
Clouds now use three layers of seamless Gaussian-union billow clusters with top/bottom
shading and lifted distance palettes; `area` controls width/depth. They use no
volumes. Mountains are full sloping heightfields with wandering ridgelines,
slope shading and atmospheric palettes. Both retain deterministic topology.
Internal material profiles are authored node graphs; recipes cannot supply
nodes, shader code or driver expressions.

See [nature API](../nature/README.md) and the published schema for exact ranges.

| `whale_like` | length 2–40, motion .2–2.5, color; continuous tapered body, curved throat pleats, separate rounded pectorals/flukes with saved hinge motion and shared body sway |

`primitive` offers cube/sphere/cylinder/cone/plane/torus, XYZ size, color and
walkability. `prop` offers the existing 17 furniture/handheld builders with
`params.kind`. None reconstructs a specific landmark or branded design.

Per-element `animation` accepts up to three layered presets: `orbit`,
`follow_path`, `bob`, `sway`, `rise`, `drift`, `spin`, `flap`, `swim`, `flicker`.
Controls are speed, phase, seed, amplitude, radius, path and axis as applicable.
Transforms use baked linear keys; wings/tails/cloth use saved native morph
drivers. No simulation cache, Python handler or runtime network is needed.
Native hero movement is present even without an explicit animation preset.
Procedural Blender motion must be baked for other applications; GLB exports
geometry/morph targets, not the driver/node evaluation engine.

## Costs and lifecycle

Hard per-recipe budgets are 20,000 internal instances, 256 placements,
400,000 estimated triangles, 1,200,000 vertices, 1,200 objects, 16 lights,
2 volumes and 200,000 transform keyframes. Internal particles/clumps and
weather particles count. Geometry is evaluated once per element before scene
mutation; polygon counts are triangulated analytically. Prop estimates reserve
8,000 triangles/16,000 vertices/40 objects per placement, including bevels.
The cost describes the recipe, not unrelated existing characters or user assets.
Warnings begin at 70% of a budget. Budget errors ask which density/count/detail
to reduce. The weather/look volume is shared according to the existing fog rules.
This is a geometry estimate; render speed depends on material, resolution and CPU.

`compose_world` replaces only the previous world. Geometry is built in a temporary
owned collection before replacement. `clear_world()` removes world objects and
unused owned data, preserves characters/other props/cameras, restores the prior
sky and still-owned look/weather, and unhides the original studio ground.
User look/weather changes made after composition are retained. World recipes and
native motion survive `.blend` save/open. `clear_environment` also clears the world.

`save_world("guardian")` saves the active recipe to workspace `worlds/guardian.json`.
Supply `recipe=...` to save without building. `load_world("guardian", build=False)`
reads and validates without scene changes; the default builds. Names are plain
identifiers; traversal and symlink files are rejected. Files are bounded to 256 KiB.

## Director, scripts and Studio

`direct_world(idea, generator="offline", seed=17)` returns recipe, brief, warnings
and costs, without Blender or a build. Offline chooses among ten seeded archetypes:
lake lanterns, mountain gateway, sky whale, floating islands, blossom valley, rice
terraces, night market, beach fire, desert ruins and snowy pines. Local keyword
rules are templates, not semantic AI interpretation; review the result.

`generator="claude"` uses the existing paid API backend; `"claude_cli"` uses
Claude Code subscription quota. Both require `consent=True`. `auto` chooses CLI,
then configured API only with consent, otherwise offline. Existing privacy,
credential redaction, tool isolation, request limits and billing reporting apply.
Prompts include the schema/catalog and composition/light/palette/scale/motion guide.
A small strict provider envelope carries the recipe as a JSON string, because
provider grammars cannot express all conditional parameters, numeric limits and
named palettes. The decoded recipe is always checked against the full published
schema and budgets before returning or building. Structured JSON undergoes one schema repair; failure visibly falls back offline
without switching to a paid provider. Network/subprocess work stays in providers.
Provider grammar limitations are documented in the [official structured-output guide](https://platform.claude.com/docs/en/build-with-claude/structured-outputs).
No live online generation is needed to run the fully mocked transport tests.

`DUNIA: guardian` / `WORLD: guardian` in text, or dict `world` containing a saved
name or inline recipe, builds the set and places the cast using `stage`.
`LOKASI` can add a conventional set as well. Script weather/look override recipe
atmosphere; lighting/cameras/dialog/sound retain their existing behavior.
Parse-only scripts retain saved names without reading files; inline recipes are
validated. Builds validate saved recipes before creating characters.

Studio's **Dunia** page offers describe → generator/consent → readable summary →
editable JSON with inline validation → 512px Eevee hero preview → save/use in Naskah.
Applying a world keeps the previous script in `char3d-world-previous-script` local
storage and adds its DUNIA header. Preview updates the active world set; characters
remain. The panel follows dark/light tokens, keyboard focus and a 390px layout.

## Verification

Pure: `.venv/bin/python tests/test_world.py` → `WORLD UNIT OK`.
Regression sections: `tests/world_regressions.py nature|outdoor|cinematic|script`
run each in isolation with one Blender. Video checks render/encode in-process;
they do not cover background worker startup or persistent speed learning.
MCP: use port **9998**, `CHAR3D_WORKSPACE=$PWD/output`, `CHAR3D_ALLOW_PYTHON=1`,
then `.venv/bin/python tests/e2e_smoke.py --world-only`.
Visuals: same port/workspace, `.venv/bin/python tests/world_visuals.py --stills`;
`--reuse --stills` inspects saved milestones; `--reuse --clips` makes two 3-second
384×216/12fps Eevee clips in the same Blender process. No second Blender is started.
Contact sheets: `output/world_sheets/quality_v2/`; stills/clips: `output/renders/world_v2_*`;
recipes: `output/worlds/showcase-*.json`; projects: `output/projects/world_v2_*.blend`. `--refresh` rebuilds the current
offline recipe around saved actors, preserving an efficient visual iteration loop.
UI on **8798**: `node tests/world_ui.cjs` records dark/light 390/1440 screenshots.
Never use production port 9876. Stop the isolated engine/UI after verification.

Stylized atmosphere and original parametric design have finite fidelity: clouds
are opaque lobes, water is not fluid/refraction, creature deformation is analytic,
and there is no dynamic collision or cloth solver. Inspect wide and character
coverage, especially hero paths, oversized scenery and foreground occlusion.
